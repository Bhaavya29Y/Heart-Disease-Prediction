# 🫀 Heart Disease Prediction using Deep Learning

This project demonstrates a heart disease prediction system using machine learning and deep learning techniques.  
The goal is to analyze cardiac-related data and build a predictive model with a simple web-based interface.


## 📌 Project Overview
- Implemented a deep learning pipeline for heart disease prediction
- Used data preprocessing, model training, and evaluation techniques
- Built a prototype web application using Streamlit for predictions


## 🛠️ Technologies Used
- Python  
- TensorFlow / Keras  
- NumPy, Pandas  
- OpenCV  
- Scikit-learn  
- Streamlit
